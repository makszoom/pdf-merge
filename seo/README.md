# seo/ — рабочие заметки по SEO pdfmerge.dev

Ведёт агент, читать может человек. Начинать с первых трёх файлов.
Методика: скилл `product-seo` (`~/AppData/Local/hermes/skills/product-seo/`).

| Путь | Что это |
|---|---|
| `site-profile.md` | продукт, кто платит, две кучи тем, решения владельца, где искать данные |
| `change-log.md` | каждое изменение сайта: дата, бэкап, даты проверок, результат |
| `lessons.md` | что сработало и что делать иначе; читать перед каждой новой страницей |
| `product-facts.md` | единственный источник правды о продукте; каждая строка с датой проверки |
| `experiments.md` | одна гипотеза на страницу и её результат |
| `data/` | выгрузки Search Console (не в git) |
| `shots/` | скриншоты проверок (не в git) |

## Как мерить

`node ~/AppData/Local/hermes/skills/product-seo/scripts/measure.mjs --page <url> --date <YYYY-MM-DD> --site sc-domain:pdfmerge.dev --log seo/change-log.md`

Скрипт сравнивает целые недели до и после даты изменения и применяет правило отката.

**Для этого сайта правило применимо напрямую**: сезонного цикла у спроса на PDF-инструменты нет.
