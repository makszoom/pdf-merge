# Product facts — pdfmerge.dev

Единственный источник правды для всего, что пишется о продукте. Собирается из самого
продукта, не из памяти и не из старых статей. Каждая строка с датой проверки.

Источник истины при расхождении: **живой сайт pdfmerge.dev**, затем владелец.

## Что делает

| Задача | Что делает продукт | Проверено | Где |
|---|---|---|---|
| Склейка PDF | объединение нескольких файлов в один, порядок задаётся пользователем | 2026-11-18 | `js/app.js` |
| Разделение | разделение файла на части по диапазонам страниц | 2026-11-18 | `js/toolkit.js` |
| Сжатие | уменьшение размера за счёт растеризации страниц (текстовый слой теряется) | 2026-11-18 | `js/toolkit.js` |
| Поворот | поворот страниц на 90/180/270 | 2026-11-18 | `js/toolkit.js` |
| Удаление страниц | выбор и удаление ненужных страниц | 2026-11-18 | `js/toolkit.js` |

Все операции выполняются **в браузере**, файлы не загружаются на сервер.

## Чего НЕ делает

| Не умеет | Проверено |
|---|---|
| Не сохраняет редактируемый текст при сжатии — страницы растеризуются | 2026-11-18 |
| Не распознаёт текст (OCR) | 2026-11-18 |
| Не редактирует содержимое страниц (только страницы целиком: поворот, порядок, удаление) | 2026-11-18 |
| Не хранит файлы: после закрытия вкладки ничего не остаётся | 2026-11-18 |
| Не требует аккаунта | 2026-11-18 |

## Платформы

Браузер: Chrome, Edge, Firefox, Safari. Хостинг GitHub Pages. Есть расширение Chrome
(`pdf-merge-extension`, готово к сабмиту в CWS, ждёт слот).

- «Your files never leave your device» — про локальную обработку.
- «5 free operations, then $5 once — no subscription» — про лимит и цену.
