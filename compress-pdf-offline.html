Two methods, and only one keeps the text

Compressors work in one of two ways and the difference decides whether your document survives intact.

The first method rewrites the file structure: it removes duplicate objects, drops unused fonts, downsamples oversized images and recompresses streams. The text layer stays exactly as it was. Acrobat and Ghostscript both do this, and so do the command line tools on Linux.

The second method renders each page to an image and builds a new PDF from those images. Compression ratios look impressive, but the text is gone. It is a picture of text now, so you cannot select it, search it, or copy a number out of an invoice.

On a Mac

Preview compresses through the Quartz filter. Open the PDF, choose File then Export, pick "Reduce File Size" from the Quartz filter dropdown and save. It keeps the text layer and works offline. The reduction is modest compared with what a rasterizing tool reports, which is the trade you want for a document you still need to read.

For more control, ColorSync Utility lets you build a custom filter with a specific image resolution. It is a fiddly dialog, and worth it only if you compress the same kind of document regularly.

On Windows

Windows has nothing built in. There is no system dialog that shrinks a PDF. Two practical options: Ghostscript, which is free and runs from the command line, and PDFsam Enhanced, which is paid. Ghostscript with the -dPDFSETTINGS=/ebook flag gets a text layer and reasonable image quality, and it takes about thirty seconds to learn.

On Android

Most Android "PDF compressor" apps upload the file to a server, because phone CPUs are slow at this. Read the permissions and the privacy policy before installing one. A browser compressor avoids the app install and keeps the file on the device, at the cost of speed on large documents.

What a browser compressor does here

PDFMerge compresses by rendering pages, which is the same approach most online compressors use. That means the output is smaller and the text layer is lost. If you need the text to stay selectable, use the Mac Export route or Ghostscript instead, and treat this tool as the option for scans and image-heavy documents.

Frequently Asked Questions

How do I compress a PDF offline on a Mac?

Open it in Preview, choose File then Export, and select "Reduce File Size" in the Quartz filter dropdown. It works without an internet connection and keeps the text selectable.

Is there a built-in PDF compressor in Windows?

No. Windows has no system tool for shrinking PDFs. Ghostscript is the free option, and the command line flag -dPDFSETTINGS=/ebook gives a sensible balance.

Why is the text not selectable after compression?

Because that compressor rebuilt the pages as images. It is the same method most online compressors use, and it trades the text layer for a smaller file. Structural compressors such as Ghostscript keep the text.

How much smaller will my PDF get?

Scanned and image-heavy documents often drop by half or more. A text-only PDF is already efficient, so expect little gain without rasterizing it.

Does compressing offline produce the same result as online?

The output depends on the method, not on where it runs. A rasterizing compressor gives the same result in a browser tab as on a server. The difference is that the file never leaves your machine.
